Colspan vs. Rowspan Mechanics

Use colspan to stretch a single cell across multiple adjacent horizontal columns (e.g. grouped headers, subtotal summaries).

Use rowspan to stretch down across vertical time or category series. Never leave hanging cells: every rowspan reduces cell count in subsequent rows!

W3C Recommendation:
Verify total cells match column span counts per row to avoid table rendering glitches.

The Critical Role of th scope>

Assistive technologies (NVDA, VoiceOver, JAWS) rely on scope="col|row|colgroup|rowgroup" to establish bidirectional context.

Without explicit scopes, visually impaired users navigating complex matrix grids lose track of what header labels apply to the active numerical data cell.

WCAG 2.1 Principle:
Criterion 1.3.1 Info and Relationships requires programmatic header association.

Tables vs CSS Grid / Flexbox

table> must never be utilized for website layout scaffolding. Tables tell screen readers: “This is correlated 2D relational data”.

Use Modern CSS Grid / Flexbox for application layout wrappers, navigation panels, and responsive device reflow.

Layout Anti-Pattern:
Layout tables break mobile responsiveness, responsive zooming, and tab sequence.
