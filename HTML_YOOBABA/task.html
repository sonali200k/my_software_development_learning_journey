The Four Pillars of Web Markup

Before building bigger pages, we must clearly understand four basic ideas: tag, element, attribute, and attribute vs property.

Pillar A: What is a Tag?

A tag is a keyword written inside angle brackets. It tells the browser what kind of content comes next. Most tags come in a pair: an opening tag and a closing tag.

Pillar B: What is an Element?

An element is the complete piece: the opening tag, the content inside, and the closing tag, all together.

Pillar C: What is an Attribute?

An attribute gives extra information to a tag. It is written inside the opening tag as a name and a value.

Pillar D: Attribute vs Property

An attribute is what we write in the HTML file. A property is the live value that the browser keeps in memory while the page is open.
