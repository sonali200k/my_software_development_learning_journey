    <h2>The Four Pillars of Web Markup</h2>

    <p>Before building bigger pages, we must clearly understand four basic ideas: tag, element, attribute, and attribute vs property.</p>

    <!-- Pillar A-->
    <h3>Pillar A: What is a Tag?</h3>
    <p>A tag is a keyword written inside angle brackets. It tells the browser what kind of content comes next. Most tags come in a pair: an opening tag and a closing tag.</p>

    <!-- Pillar B-->
    <h3>Pillar B: What is an Element?</h3>
    <p>An element is the complete piece: the opening tag, the content inside, and the closing tag, all together.</p>

    <!-- Pillar C-->
    <h3>Pillar C: What is an Attribute?</h3>
    <p>An attribute gives extra information to a tag. It is written inside the opening tag as a name and a value.</p>

    <!-- Pillar D-->
    <h3>Pillar D: Attribute vs Property</h3>
    <p>An attribute is what we write in the HTML file. A property is the live value that the browser keeps in memory while the page is open.</p>
